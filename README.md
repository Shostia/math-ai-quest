# Точка дотику

Особистий квест для вчителя математики 5–9 класів. Шість станцій ведуть від визначення навчальної мети до апробації десятихвилинного фрагмента уроку. Усі приклади вбудовані. Для проходження не потрібні акаунт чи доступ до чатбота.

## Як пройти

Відкрийте index.html у браузері. Оберіть тему зі свого календарного плану. На кожній станції прочитайте ситуацію, оберіть відповідь, ознайомтеся з поясненням і додайте власне педагогічне рішення. Завершення станції фіксує вибір правильної відповіді та наявність запису. Зміст відкритих відповідей учитель оцінює самостійно. Записи можна завантажити в текстовий файл у будь-який момент. Прогрес прив’язаний до браузера та адреси сайту.

## Як опублікувати на GitHub Pages

1. Створіть публічний репозиторій GitHub або відкрийте відповідний наявний репозиторій.
2. Завантажте розпаковані index.html та README.md у корінь гілки main і збережіть зміни комітом.
3. Відкрийте Settings → Pages. У Build and deployment виберіть Deploy from a branch, гілку main та папку /(root). Натисніть Save.
4. Після завершення розгортання відкрийте Visit site у розділі Pages.

[Інструкція GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Як адаптувати

Запитання, варіанти відповідей, пояснення й практичні завдання містяться в масиві missions у файлі index.html. Поле ok задає індекс правильної відповіді, починаючи з 0. Джерела зібрано в масиві refs і доступно на сторінці квесту. Для локального проходження інтернет потрібен лише для переходу до зовнішніх джерел.
